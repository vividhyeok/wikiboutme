## 2. 성향

새로운 아이디어를 빠르게 시험하고, 실제로 써 본 뒤 불편한 지점을 다시 고치는 반복을 선호한다. 이미 존재하는 도구라도 자신의 작업 방식과 맞지 않으면 직접 더 단순한 버전을 만드는 경우가 많다.

설명이나 학습에서는 아래에서부터 정의를 쌓는 방식보다 **전체 구조를 먼저 파악한 뒤 세부로 내려가는 탑다운 방식**을 선호한다.

## 3. 개발 취향

- CLI를 선호한다.
- 빠르게 프로토타입을 만든 뒤 실제 사용하면서 수정하는 편이다.
- 불필요한 버튼이나 UI 요소가 많은 것을 싫어한다.
- PC만이 아니라 태블릿과 모바일에서 자연스럽게 이어지는 사용성을 중요하게 본다.
- 반복적인 수동 작업을 자동화하는 데 관심이 많다.

## 4. 관심사

개발 외에도 음악 제작, 스케이트보드, 영화와 드라마, 패션과 헤어스타일, 게임 등에 관심이 있다.
