## 1. AI 활용 방식

AI를 단순 검색창처럼 사용하기보다, **목적·맥락·제약을 충분히 제공하고 계획부터 구현까지 맡기는 방식**을 선호한다.

특히 복잡한 작업에서는 AI가 먼저 전체 구조를 잡고 스스로 필요한 단계를 나눠 진행하는 흐름을 선호한다.

## 2. 주로 사용하는 도구

사용 경험이 있는 도구에는 ChatGPT, Claude, Gemini, GitHub Copilot과 여러 CLI 기반 AI 도구가 있다.

CLI가 가볍고 빠르다는 이유로 터미널 기반 개발 흐름을 선호하며, 코드 수정과 배포를 가능한 한 짧은 루프로 이어가려고 한다.

## 3. 학습 자동화

강의 음성이나 영상의 STT를 보정하고, 내용을 구조화된 노트나 학습 자료로 만드는 흐름에 관심이 많다.

예를 들면 다음과 같다.

1. 강의 녹음 또는 영상
2. STT
3. AI를 이용한 오류 보정
4. 개념 구조화
5. Markdown/PDF 형태로 저장
6. 다시 검색하거나 복습에 활용

## 4. AI에 대한 관점

생성형 AI가 빠르게 발전하면서 단순한 "AI 기능이 들어간 앱" 자체의 희소성은 줄어들었다고 본다. 그래서 새로운 프로젝트를 만들 때는 AI를 붙였다는 사실보다, 실제 사용자가 어떤 문제를 해결하는지와 교육적·실용적 의미를 더 중요하게 본다.
